SIMPLE WORKFLOW

How to compress an image

  1. Select an image. Choose a supported image from your device.
  2. Adjust quality. Lower quality can reduce file size, but may affect image detail.
  3. Compress and compare. Review the output size before saving.
  4. Download. Save the compressed image to your device.

COMMON QUESTIONS

Frequently asked questions

Are my images uploaded?

This version processes images locally in your browser. The image file is not sent to this site's server by the compression code. Other browser extensions or third-party scripts may behave independently; this starter site does not include analytics or advertising scripts.

Will compression always make a file smaller?

No. The result depends on the original image, output format, dimensions, and quality setting. Check the result size before downloading.

Can I make an image exactly 100 KB?

This version provides a quality control, not a guaranteed target-size mode. Exact file sizes require an iterative process and may not be possible for every image and format.
