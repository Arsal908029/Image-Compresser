Image compression FAQ

Does this tool upload my image?

The compression logic runs in your browser and does not upload the selected image to this website. This statement should be reviewed if you add third-party scripts or server-side features later.

Why did my PNG become larger?

Some images do not compress well when converted. Try WebP or JPEG if transparency is not required. JPEG does not preserve transparency.

Can this guarantee an image under 100 KB?

No. The current version adjusts quality but does not guarantee an exact target size. A target-size feature can be added as a later improvement.
